# Kwik 112 Round 2 Implementation Plan

**Goal:** Reframe the existing dispatch build as Kwik 112: a voice-first 112 call emulator backed by an auditable human dispatch console, then ship rubric-aligned public evidence and machine-readable discovery artifacts.

**Architecture:** Preserve the existing Hume/scripted voice station, local-create/model-refine call pipeline, dashboard state, decision timeline, reservation locks, and evaluation harness. Add only two small reusable browser contracts: live-call event payloads and deterministic pre-arrival guidance selection. Keep the public landing page server-rendered and link into the existing dashboard call station.
